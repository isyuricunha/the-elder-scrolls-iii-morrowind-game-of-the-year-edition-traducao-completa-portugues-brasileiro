## 📜 Sobre a tradução

Um dos maiores clássicos dos RPGs agora pode ser explorado em **Português Brasileiro (PT-BR)**!

Este projeto oferece uma tradução completa de **The Elder Scrolls III: Morrowind — Game of the Year Edition**, incluindo o jogo original e suas duas expansões oficiais: **Tribunal** e **Bloodmoon**.

O objetivo é permitir que jogadores brasileiros mergulhem na história de Vvardenfell, acompanhem os mistérios do Nerevarine e descubram a riqueza narrativa de Tamriel sem depender do inglês.

A tradução abrange diálogos, missões, livros, registros do diário, itens, equipamentos, magias, personagens, facções e outros conteúdos presentes nos arquivos principais do jogo.

Mais do que traduzir palavras, o projeto busca preservar a atmosfera de Morrowind, suas tradições, seus conflitos e a identidade de um dos universos mais fascinantes dos RPGs.

## 🛠️ Como instalar a tradução

A instalação é simples e não exige programas adicionais para modificar os arquivos.

Entretanto, **é importante fazer backup dos arquivos originais antes de continuar**.

### 1. Localize a pasta do jogo

Se você utiliza a Steam:

1. Abra sua biblioteca.
2. Clique com o botão direito em **Morrowind**.
3. Selecione **Gerenciar → Procurar arquivos locais**.
4. Abra a pasta `Data Files`.

Exemplos de caminhos:

**Steam**

```text
C:\Program Files (x86)\Steam\steamapps\common\Morrowind\Data Files
```

**GOG**

```text
C:\GOG Games\Morrowind\Data Files
```

Em instalações personalizadas, encontre a pasta que contém o arquivo `Morrowind.exe`. Dentro dela estará a pasta `Data Files`.

### 2. Faça backup dos arquivos originais

Antes de substituir qualquer arquivo, localize:

```text
Morrowind.esm
Tribunal.esm
Bloodmoon.esm
```

Copie os três arquivos para uma pasta de segurança, como `backup-original`.

> ⚠️ **Atenção:** esses arquivos são fundamentais para o funcionamento do jogo. A tradução substitui os arquivos mestres originais, então guardar uma cópia permite restaurá-los posteriormente.

### 3. Instale os arquivos traduzidos

1. Abra a pasta `traducao` do pacote baixado.
2. Selecione os três arquivos `.esm`.
3. Copie-os para a pasta `Data Files`.
4. Confirme a substituição dos arquivos existentes.

A estrutura final será:

```text
Morrowind/
├── Morrowind.exe
├── Morrowind.ini
└── Data Files/
    ├── Morrowind.esm       ← Traduzido
    ├── Tribunal.esm        ← Traduzido
    ├── Bloodmoon.esm       ← Traduzido
    └── ...
```

**Não é necessário ativar um novo mod no launcher.**

### 4. Inicie sua aventura

Abra Morrowind normalmente.

Os textos dos três arquivos mestres estarão em Português Brasileiro.

> 💡 **Recomendação:** comece uma nova partida depois de instalar ou atualizar a tradução. Isso ajuda a evitar problemas com referências, diálogos e informações armazenadas em saves anteriores.

## 🎭 Questionário de criação de classe — Opcional

Durante a criação de personagem, Morrowind pode apresentar um questionário com **dez perguntas e trinta respostas**, utilizado para sugerir uma classe inicial.

Esses textos não estão armazenados diretamente nos arquivos `.esm`:

- No Morrowind clássico, ficam no `Morrowind.ini`.
- No OpenMW, são configurados por entradas `fallback` no `openmw.cfg`.

Por esse motivo, o projeto inclui um complemento opcional para traduzir o questionário.

**Importante:** o `Morrowind.esm` traduzido já contém a correção para o erro que podia ocorrer ao concluir o questionário, como `Unable to locate Class "Ladrao"`.

Portanto, quem instalar somente os três arquivos `.esm` poderá concluir a criação do personagem normalmente, mas as dez perguntas continuarão em inglês sem o complemento opcional.

### 🖥️ Morrowind clássico — Windows

1. Abra a pasta:

   ```text
   opcional-questionario-classes\Morrowind-classico
   ```

2. Copie a pasta `Morrowind-classico` inteira para a pasta principal do jogo, ao lado de `Morrowind.exe` e `Morrowind.ini`.
3. Abra a pasta que você copiou.
4. Execute `instalar-questionario-classes.bat`.

O instalador identifica o `Morrowind.ini`, cria automaticamente um backup com data e hora e altera apenas as seções `[Question 1]` até `[Question 10]`.

As demais configurações são preservadas.

Se o Windows negar permissão de escrita em uma instalação dentro de `Program Files`, pode ser necessário executar o instalador como administrador.

### 🌐 OpenMW

1. Abra o arquivo `opcional-questionario-classes\OpenMW\openmw.cfg.questionario-classes`.
2. Copie todas as linhas iniciadas por `fallback=`.
3. Localize o `openmw.cfg` utilizado pela sua instalação.
4. Cole as linhas ao final do arquivo.
5. Salve e inicie o OpenMW.

O caminho do arquivo de configuração depende do sistema operacional.

### 🐧 Linux, macOS, Wine e Proton

Os três arquivos `.esm` são instalados normalmente na pasta de dados do jogo.

O instalador `.bat` foi desenvolvido para Windows. Para traduzir o questionário em outros ambientes, utilize manualmente os arquivos de configuração incluídos no pacote.

## ⚙️ Compatibilidade

A tradução principal utiliza os arquivos oficiais de Morrowind, Tribunal e Bloodmoon.

| Ambiente | Tradução principal | Questionário opcional |
|---|:---:|---|
| Morrowind clássico — Windows | ✅ | Instalador `.bat` |

| Instalação personalizada | ✅ | Conforme o ambiente |
| OpenMW — Windows | ✅ | Configuração manual |
| OpenMW — Linux/macOS | ✅ | Configuração manual |

### Requisitos

- **The Elder Scrolls III: Morrowind — Game of the Year Edition**.
- Expansões **Tribunal** e **Bloodmoon**.
- Programa para extrair arquivos ZIP ou 7Z, conforme o pacote baixado.

### Observações importantes

- A tradução não adiciona dublagem em português.
- Os três arquivos mestres originais são substituídos.
- Outros mods que alteram os mesmos registros podem exigir ajustes de compatibilidade.
- É recomendado iniciar uma nova partida após instalar ou atualizar.
- No OpenMW, a tradução precisa ser instalada na pasta de dados que o motor realmente utiliza.

## 🔄 Atualizações e melhorias

Traduzir um RPG da dimensão de Morrowind é um trabalho que exige atenção constante.

Além do jogo principal, Tribunal e Bloodmoon possuem uma enorme quantidade de diálogos, missões, livros, descrições e referências internas que precisam permanecer consistentes entre si.

O projeto recebe revisões para aprimorar a qualidade dos textos e corrigir problemas identificados pela comunidade.

### Melhorias já realizadas

- Correção de tópicos de conversa relacionados à progressão de missões.
- Padronização de nomes de armas, armaduras, livros e ingredientes.
- Revisão de textos entre o jogo base e as expansões.
- Correção de referências inconsistentes entre personagens, locais e diálogos.
- Revisão de títulos de livros, pergaminhos e documentos.
- Ajustes na formatação de sermões, cartas e textos históricos.
- Correção de nomes de interiores, facções e organizações.
- Correção de textos remanescentes em inglês.
- Correções específicas de diálogos e carregamento em Tribunal e Bloodmoon.

### Como atualizar

1. Baixe a versão mais recente pelo Nexus Mods ou GitHub Releases.
2. Guarde uma cópia da versão anterior, se desejar.
3. Substitua novamente os três arquivos `.esm` na pasta `Data Files`.
4. Atualize o questionário opcional, caso o pacote tenha recebido alterações.
5. Inicie uma nova partida quando houver modificações relevantes em diálogos, scripts ou registros.

## ♻️ Como remover a tradução

### Tradução principal

1. Feche o jogo.
2. Abra a pasta `Data Files`.
3. Localize o backup dos três arquivos originais.
4. Restaure `Morrowind.esm`, `Tribunal.esm` e `Bloodmoon.esm`.
5. Confirme a substituição.

Também é possível utilizar a verificação de integridade dos arquivos pela Steam ou GOG Galaxy, mas isso pode desfazer outras modificações instaladas.

### Questionário opcional

O instalador do Morrowind clássico cria um backup semelhante a:

```text
Morrowind.ini.backup-20260727-153000
```

Para restaurar, feche o jogo e devolva ao backup escolhido o nome `Morrowind.ini`, preservando uma cópia da configuração atual se necessário.

No OpenMW, remova as linhas `fallback=` adicionadas pelo complemento.

## 🧭 Solução de problemas

<details>
<summary><b>O jogo continua em inglês</b></summary>

Verifique se os três arquivos `.esm` foram copiados para a pasta `Data Files` correta.

Caso existam múltiplas instalações do jogo, confirme qual delas está sendo executada.

No OpenMW, confira a pasta de dados configurada no launcher.

</details>

<details>
<summary><b>O questionário ainda aparece em inglês</b></summary>

A tradução principal não inclui as perguntas armazenadas fora dos arquivos `.esm`.

No Morrowind clássico, execute `instalar-questionario-classes.bat`.

No OpenMW, adicione as entradas `fallback=` do complemento ao `openmw.cfg`.

</details>

<details>
<summary><b>O instalador não encontra Morrowind.ini</b></summary>

Copie a pasta `Morrowind-classico` inteira para a pasta principal do jogo, ao lado de `Morrowind.exe` e `Morrowind.ini`.

Não execute o instalador diretamente da pasta Downloads.

</details>

<details>
<summary><b>O Windows não permite substituir os arquivos</b></summary>

Feche o jogo e o launcher antes de copiar os arquivos.

Se o jogo estiver instalado dentro de `Program Files`, o Windows pode exigir permissão de administrador.

</details>

<details>
<summary><b>Uso OpenMW e a tradução não aparece</b></summary>

Verifique se você substituiu os arquivos `.esm` na pasta de dados efetivamente utilizada pelo OpenMW.

Algumas instalações usam cópias separadas dos arquivos originais.

</details>

<details>
<summary><b>Encontrei um erro de diálogo ou missão</b></summary>

Informe a versão da tradução, o motor utilizado (Morrowind clássico ou OpenMW), o nome da missão e uma descrição do problema.

Se possível, inclua uma captura de tela.

</details>
